# 02｜重要极限与等价无穷小

[知识目录](../README.md) · [学习进度](../progress.md) · [错题](../mistakes/mistake-log.md)

> 整理者讲义 [C]。本章核心不是背公式，而是检查**趋近条件和表达式结构**。

## 30 秒回顾

- 当 x→0（弧度制），**sin x / x → 1**。
- 当 t→0 且 1+t>0，**(1+t)^(1/t) → e**。
- x→0 时，**sin x ∼ x**；**1 − cos x ∼ x²/2**。
- **等价无穷小不能在会发生主要项抵消的加减式中直接替换。**

## 1．重要极限：sin x / x

**标准式：** x→0 时，sin x / x → 1。

**例题：** x→0 时，sin(3x)/x 的极限。

1. 分子出现 sin(3x)，所以凑出 3x。
2. sin(3x)/x = 3 × [sin(3x)/(3x)]。
3. 中括号趋于 1，**答案：3**。

注意：角度按**弧度**计算。

## 2．重要极限：指数型

**标准式：** t→0 时，(1+t)^(1/t) → e。

更常用的是：如果 u(x)→0、底数 1+u(x)>0 且 u(x)v(x)→A（有限常数），那么

**(1+u(x))^v(x) → e^A**。

**例题：** x→0 时，(1+2x)^(1/x)。

- 底数趋于 1，指数绝对值变大，属于 1^∞ 型未定式。
- 取对数：ln y = ln(1+2x)/x。
- 因为 ln(1+2x)/(2x)→1，所以 ln y→2。
- **答案：e²，而不是 e。**

以前的练习还出现过 e⁻⁶ 等结果；关键是算清指数对应的极限。

## 3．等价无穷小速查

以下均在 x→0 时使用：

- **sin x ∼ x**
- **tan x ∼ x**
- **1 − cos x ∼ x²/2**
- **ln(1+x) ∼ x**（1+x>0）
- **eˣ − 1 ∼ x**

其中“a ∼ b”表示 **a/b → 1**，而且这里讨论的是两者均趋于 0 的情形。

**例题：** (1 − cos x)/x² → **1/2**。

## 4．同阶、高阶、等价，怎样区分？

比较两个无穷小 α 和 β，研究 α/β：

- 趋于**非零有限数** → 同阶。
- 趋于 **1** → 等价（同时也是同阶）。
- 趋于 **0** → α 比 β 高阶。

例如：x² 比 x 高阶；2x 与 x 同阶，但不等价。

## 5．重点陷阱：加减不能机械替换

考虑 **sin x − x**。

虽然 sin x ∼ x，但直接替换会变成 x − x = 0，抹掉真正需要研究的更高阶差值。

**安全顺序：** 判断是否有主要项抵消 → 选择恒等变形、洛必达或合适的更高阶工具 → 再求极限。

## 6．指数型未定式怎么办？

遇到 1^∞，不要直接答 1 或 e。

1. 确认底数在所研究的邻域**大于 0**。
2. 设 y = [1+u(x)]^v(x)。
3. 取对数：ln y = v(x) × ln(1+u(x))。
4. 先求 ln y 的极限 A，再得到原式极限 e^A。

关联重点错题：[M06](../mistakes/mistake-log.md)。
