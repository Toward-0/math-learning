# 06｜洛必达法则与综合极限

[知识目录](../README.md) · [学习进度](../progress.md) · [错题 M06](../mistakes/mistake-log.md)

> 整理者讲义 [C]。**当前仍在巩固**，看懂下面的示范不等于已经独立掌握。

## 30 秒回顾

- 洛必达主要处理符合条件的 **0/0** 和 **∞/∞** 型分式极限。
- **分子、分母分别求导**；不是对整个商使用商法则。
- 0×∞、∞−∞ 要先转换形式。
- **1^∞ 不是 1**；通常先在底数为正的邻域取对数。

## 1．洛必达法则：什么时候能用？

需要先确认以下条件：

1. 当前分式呈 0/0 或 ∞/∞ 型。
2. 分子、分母在所考察的去心邻域内可导，且分母导数不为 0。
3. 导数之商的极限存在（有限或允许的无穷极限）。
4. 满足定理其他适用前提后，才可以把原分式的极限转为导数商的极限。

**口诀：先判形式，再分别求导，每次继续使用前重新检查。**

## 2．例题：指数函数

求 x→0 时，(e^(2x)−1)/x 的极限。

1. 直接代入为 0/0。
2. 分子求导是 2e^(2x)，分母求导是 1。
3. x→0，得到 2e⁰=2。

**答案：2。**

这是旧学习中已正确求出的类型。

## 3．例题：需要连续两次洛必达

求 x→0 时，(x−sin x)/x³ 的极限。

**第 1 次：**

分子导数为 1−cos x，分母导数为 3x²。

得到 (1−cos x)/(3x²)，仍是 0/0。

**第 2 次：**

分子导数为 sin x，分母导数为 6x。

得到 sin x/(6x)，极限为 **1/6**。

> **易错提醒：** 第二次分母是 6x，不是 3x。每次求导都要重新检查。

## 4．例题：x² ln x 为什么趋于 0？

求 x→0⁺ 时 x² ln x 的极限。

**第 1 步：** 原式是“0 × (−∞)”型，不能直接洛必达。

**第 2 步：** 改写成分式：

**x² ln x = (ln x)/(1/x²)**

此时是 (−∞)/(+∞)，符合 ∞/∞ 类型。

**第 3 步：** 分别求导：

- 分子：(ln x)′ = 1/x。
- 分母：(1/x²)′ = −2/x³。

得到：

**(1/x)/(−2/x³) = −x²/2 → 0**

**答案：0。**

旧学习中最终答案正确，但曾漏写分母求导的系数 2，见 [M07](../mistakes/mistake-log.md)。

## 5．重点错题：1^∞ 绝不一定是 1

求 x→0 时：

**L = (sin x / x)^(1/x²) 的极限**

**第 1 步｜识别形式**

底数 sin x / x →1，指数 1/x²→+∞，属于 **1^∞ 未定式**。

**第 2 步｜取对数**

在 0 附近（x≠0），sin x/x>0。设原表达式为 y，则：

**ln y = ln(sin x/x) / x²**

**第 3 步｜使用对数等价关系**

令 u=sin x/x−1，则 u→0，且 ln(1+u) ∼ u。

所以 ln y 与下面的表达式具有相同极限：

**(sin x/x−1)/x² = (sin x−x)/x³**

**第 4 步｜连接前面的旧题**

第三节已算出 (x−sin x)/x³→1/6，因此：

**ln y→−1/6**

将对数还原，得到：

**最终答案：e^(−1/6)**。

> **最值得复习的地方：** 这道题不是考新技巧，而是把“取对数、等价无穷小、洛必达”串联起来。

关联错题：[M06](../mistakes/mistake-log.md)。

## 6．做综合极限前的检查清单

- [ ] 当前形式是 0/0、∞/∞，还是其他未定式？
- [ ] 洛必达适用条件是否满足？
- [ ] 链式法则与系数有没有漏？
- [ ] 若是指数型，底数是否在邻域内为正？
- [ ] 需要区分左右极限吗？
- [ ] 最终答案与推理是否对应？
