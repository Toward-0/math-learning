## 每篇知识笔记怎么读？

1. **30 秒回顾**：先看结论和使用条件。
2. **一两个代表例题**：按步骤推导，不一次性看完答案。
3. **易错点**：对照自己此前犯过的错误。
4. **闭卷自检**：离开笔记独立做，结果才记录为已掌握的证据。

手机优先：知识笔记采用 **Unicode 数学符号 + 分行短式**，例如 **f′(c) = [f(b)−f(a)]/(b−a)**。这样即使 GitHub 手机 App 不显示 LaTeX，核心公式也能阅读。复杂公式以后可单独附网页版排版或图片，但不能以图片取代可搜索的文字说明。

## 最小维护流程

- **新知识**：只在所属章节补充值得长期保存的原理和使用条件。
- **有代表性的练习**：存入 [练习记录](practice/representative-problems.md)，注明独立或提示后。
- **典型错误**：更新 [错题台账](mistakes/mistake-log.md)，保留旧错误和修正理由。
- **隔几天复测**：更新 [复习队列](reviews/review-queue.md)。
- **真正掌握新内容**：最后才更新 [progress.md](progress.md)。

默认可以在学习当日、约 3 天与 7 天后复测；具体以遗忘情况灵活调整。
