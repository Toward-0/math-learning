# 03｜导数：从变化率到求导法则

## 30 秒回顾

- **导数**表示某一点的瞬时变化率，也是切线的斜率。
- 导数存在 ⇒ 函数连续；反过来不一定成立。
- **乘积求导**： (fg)′ = f′g + fg′。
- **链式法则**：先求外层，再乘内层导数。

## 1．导数的定义

在 x=a 处：

**f′(a) = lim(h→0) [f(a+h) − f(a)] / h**

这里的 h 表示自变量增加的一小段量。导数就是割线斜率在 h 趋于 0 时的极限（极限存在时）。

**从定义推导 x² 的导数：**

1. [(x+h)² − x²]/h
2. = (2xh+h²)/h
3. = 2x+h（h≠0）
4. h→0，得到 **(x²)′ = 2x**。

旧学习还从定义理解过 (x³)′=3x²。

## 2．求导规则速查

- **幂函数：** (xⁿ)′ = n xⁿ⁻¹（在适用的定义域内）。
- **和差：** (f ± g)′ = f′ ± g′。
- **乘积：** (fg)′ = f′g + fg′。
- **商：** (f/g)′ = (f′g − fg′)/g²（g≠0）。
- **复合函数：** [f(g(x))]′ = f′(g(x)) × g′(x)。

**特别注意：** 乘积不是把两个导数简单相乘；商法则分子有减号，而且分母是 g²。

## 3．例题：商法则

求 (x²+1)/(x+1) 的导数（x≠−1）。

1. 分子 f=x²+1，分母 g=x+1。
2. 分别求导：f′=2x，g′=1。
3. 代入商法则：

**[(x²+1)/(x+1)]′ = [2x(x+1) − (x²+1)]/(x+1)²**

整理后得到：

**(x²+2x−1)/(x+1)²**

该类型在旧学习中曾正确完成。

## 4．例题：链式法则

求 (x²+1)³ 的导数。

- 外层是三次方：3(x²+1)²。
- 内层 x²+1 的导数：2x。
- 两者相乘，**答案：6x(x²+1)²**。

## 5．切线方程

在可导点 x=a，已知切点 (a,f(a)) 和斜率 f′(a)，切线方程：

**y − f(a) = f′(a)(x − a)**

只算斜率还不够，要代入切点。

## 6．常用函数与高阶导数

- (eˣ)′ = eˣ。
- (ln x)′ = 1/x（x>0）。
- (sin x)′ = cos x。
- (cos x)′ = −sin x。
- [ln(g(x))]′ = g′(x)/g(x)（在 g(x)>0 的区域）。

**二阶导数 f″(x)** 是对一阶导数继续求导；三阶导数记作 f‴(x)。

例如 f(x)=x³−6x²+9x：

- f′(x)=3x²−12x+9
- f″(x)=6x−12

**不要误解：** f″(a)=0 不代表这段图像是直线。
